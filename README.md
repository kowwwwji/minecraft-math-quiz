# minecraft-math-quiz

小学 1〜2 年生向けの「算数ダンジョン」を Minecraft Java 版のデータパックとして作る。
部屋に浮かぶ問題（例 `3 + 4 + 2 = ?`）に 3 つのボタンで答え、正解なら扉が開き、
不正解なら足元が抜けて水の穴に落ちる。問題は毎回ランダム。

仕様は設計書 `docs/superpowers/specs/2026-11-06-math-dungeon-design.md` が正。

## 使い方（親の操作）

1. `./install.sh` でデータパックを生成し、ワールド `さんすう` の `datapacks/` へコピーする
   （別のワールドに入れるときは `WORLD=/path/to/world ./install.sh`）。
2. ワールドを開いて `/reload`。
3. `/function mathquiz:setup` でダンジョンを建てる（一度だけ。再実行で建て直し）。
4. `/function mathquiz:start` で子どもを 1 部屋目に送り、問題を出す。
5. 遊び終わったら `/function mathquiz:quit`。クリエイティブに戻し、`setup` を打った場所へ戻る。

不正解はダンジョン全体で 3 回まで。3 回目は足元の TNT が爆発して子どもは死に、`setup` を打った場所に
リスポーンして遊びは終わり（遊び直すなら `start`）。`setup` はこのとき持ち物が散らばらないよう
`keepInventory` を有効にする。

難易度は `start` の前後どちらで切り替えてもよい（次の問題から反映）。名前は「学年_段階」。

| 関数 | 内容 | 答えの範囲 |
|------|------|-----------|
| `/function mathquiz:level/g1_easy` | 3 つの数の足し算だけ（`2 + 3 + 1`） | 0〜10 |
| `/function mathquiz:level/g1_normal` | 3 つの数の足し算・引き算混じり（`5 + 3 - 2`）。既定 | 0〜10 |
| `/function mathquiz:level/g1_hard` | 同上 | 0〜20 |
| `/function mathquiz:level/g2_easy` | 2 桁の足し算・引き算（`47 + 28`、`63 - 19`） | 0〜99 |
| `/function mathquiz:level/g2_normal` | 2 桁の足し算・引き算と九九（`7 × 8`）を半々 | 0〜99 |
| `/function mathquiz:level/g2_hard` | 2 桁の 3 つの数の足し算・引き算（`23 + 45 - 18`）と九九を半々 | 0〜99 |

## 動作確認の手順

データパックを変えたら、この順に確認する。

1. `/reload` のあと `/function mathquiz:setup`。1 秒ほどで空中（y=120）に石レンガの建物ができ、
   入口に立っていること。
2. `/function mathquiz:start` で部屋 1 に入り、正面の壁の上に問題、赤・黄・青の的に付いた木のボタンの
   上に数字が大きく見えること。
3. 正解のボタンを押す。「せいかい！」が出て音が鳴り、右（+X）側の鉄格子が消えること。
4. 次の部屋で不正解のボタンを押す。「ざんねん… あと 2 かい」が出て落ち、水に着水してダメージが無いこと。
   はしごで部屋に戻れ、3 秒後に床が戻って新しい問題が出ていること。
   はしごを登り切った場所からボタンを連打しても、新しい問題が勝手に答えられないこと。
5. 不正解を合計 3 回にする。「ばくはつ！」が出て足元の TNT が点滅し、2 秒後に爆発音と煙で死ぬこと。
   部屋が壊れていないこと。リスポーンすると `setup` を打った場所に立ち、クリエイティブに戻って
   「もういちど あそぶなら …」の案内が出ること。
6. `start` からやり直し、5 部屋クリアで扉が開くこと。ゴール部屋に入った瞬間に「ゴール！」と音、頭上の
   ガラス越しに花火が 3 回上がり、ダメージが無いこと。宝箱があること。
7. `/function mathquiz:level/g2_hard` に切り替え、次の問題から 2 桁の 3 つの数の式か九九（`7 × 8 = ?`）が
   出ること。3 桁の数が式にも選択肢にも出ないこと。式が壁の幅に収まって読めること。
   九九の選択肢が `56` `48` `63` のように表の隣の数になっていること。

## 開発

- テスト: `python3 -m unittest`
- 生成のみ: `python3 build.py`（`dist/mathquiz/` に書き出す。`--out` で変更可）
- 座標・部屋数・難易度は `builder/config.py`
